# 📊 Task 6: Monthly Revenue and Order Volume Analysis

## Overview

This project focuses on analyzing **monthly sales trends** by examining **revenue** and **order volume** using SQL aggregation techniques. It is part of a hands-on data analytics internship where I worked with relational databases (MySQL) to derive business insights from e-commerce transactional data.

---

## 📌 Objectives

- Identify monthly trends in total revenue and order activity.
- Understand peak-performing months and seasonal patterns.
- Apply SQL aggregation functions and grouping techniques for business intelligence.

---

## 🧰 Tools & Technologies

- **Database:** MySQL  
- **Language:** SQL  
- **Environment:** Local MySQL Workbench  
- **Tables Used:** Orders, Customers, Products, Order_Items  

---

## 🔍 Analysis Performed

- **Revenue Analysis:** Tracked total monthly revenue using aggregation.
- **Order Volume Analysis:** Counted distinct orders per month to understand customer activity.
- **Time-Based Grouping:** Grouped and sorted results by both **year** and **month**.
- **Top Performers:** Identified top 3 months with highest sales using sorting and filtering.

---

## 📈 Key Insights

- Determined revenue distribution across different months to uncover potential seasonality.
- Identified high-traffic months to help the business optimize promotions and inventory.
- Demonstrated how SQL can turn raw transactional data into actionable trends.

---

## 🧠 Skills Demonstrated

- Writing clean, structured SQL for real-world datasets
- Using aggregation functions like `SUM()` and `COUNT(DISTINCT ...)`
- Applying `GROUP BY`, `ORDER BY`, and filtering for time-based trends
- Presenting insights clearly from structured data
